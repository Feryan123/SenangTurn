# SenangTurn

Interactive demo of SenangTurn (CC0007 Group 28): a freestanding, no-electricity frame that lets a senior caregiver turn a bedbound partner alone.

Plain static site — `index.html`, `styles.css`, `script.js`. No build step.

## Run locally

Open `index.html` in a browser, or serve the folder:

```sh
npx serve .
```

## Deploy

Import the repo into Vercel with Framework Preset **Other** and no build command.
